## What it does

Reverse-lookup glossary that turns a vague description of a web animation or motion effect into its exact term, so the user knows what to ask for. Naming only, it does not design or build the effect.

## When to reach for it

Type /animation-vocabulary when the user asks "what's it called when…" or describes a motion effect without knowing its name.

## Common questions

**Does this skill work across multiple AI agent tools?**
Yes. It supports Claude Code, OpenAI Codex, DeepSeek Harness (DSH), and standard Agent Skills ecosystem tools.

## It's working if

- The best-match term comes first, with 1–2 alternates and a one-line note on how they differ.

## Where it fits

Vocabulary layer underneath design and animation work.
