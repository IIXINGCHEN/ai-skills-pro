## What it does

Specialized review skill: reviews animation and motion code against a high craft bar derived from Emil Kowalski's design engineering philosophy. Defaults to flagging; approval is earned. Never modifies source code.

## When to reach for it

Type /review-animations when reviewing animation code in a diff or auditing existing motion.

## Common questions

**Does this skill work across multiple AI agent tools?**
Yes. It supports Claude Code, OpenAI Codex, DeepSeek Harness (DSH), and standard Agent Skills ecosystem tools.

## It's working if

- Every animation measured against the ten non-negotiable standards; violations are findings.
- Tiered output with explicit approval criteria.

## Where it fits

Code review for motion; pairs with improve-animations.
