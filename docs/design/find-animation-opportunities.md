## What it does

Search skill with one job: sweep an interface for moments that would genuinely benefit from motion and propose a precise recipe for each. It is a filter as much as a finder, most candidates get rejected. Read-only; it never modifies source code.

## When to reach for it

Type /find-animation-opportunities when asking "what could be animated here?" or wanting to make an interface feel more alive.

## Common questions

**Does this skill work across multiple AI agent tools?**
Yes. It supports Claude Code, OpenAI Codex, DeepSeek Harness (DSH), and standard Agent Skills ecosystem tools.

## It's working if

- A short list of high-conviction opportunities, each with exact values.
- Most candidates rejected with reasons; no blanket animation-everywhere.

## Where it fits

Before improve-animations and review-animations; discovery, not implementation.
