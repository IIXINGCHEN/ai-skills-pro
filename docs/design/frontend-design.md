## What it does

Design-lead approach to distinctive visual identity: deliberate, opinionated choices about palette, typography, and layout grounded in the brief's subject matter, never templated defaults.

## When to reach for it

Type /frontend-design when building new UI or reshaping existing UI with a distinct point of view.

## Common questions

**Does this skill work across multiple AI agent tools?**
Yes. It supports Claude Code, OpenAI Codex, DeepSeek Harness (DSH), and standard Agent Skills ecosystem tools.

## It's working if

- Choices are specific to the brief, not interchangeable.
- Typography carries personality; none of the common generated-page tells.

## Where it fits

New pages, landing pages, redesigns; upstream of implementation.
