## What it does

Executes first-principles adversarial code audits and architecture health checks on mission-critical components. The auditor stance is independent: attack surface derived before reading prior analyses or author rationale, then an active counterexample and failure-scenario hunt with every finding citing file, line, or run output.

## When to reach for it

Type `/eng-adversarial-audit`, or the agent reaches for it automatically when a task fits: security or concurrency audits.
