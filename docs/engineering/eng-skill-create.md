## What it does

Authors one complete new skill in this repository end to end: it runs three intake gates (enterprise fit, worth building, no duplicate), freezes the design with you, scaffolds the three files from the template, wires every catalog surface from the authoring checklist, drives all four quality gates to green, then links, records a changeset, and appends the execution record.

## When to reach for it

You invoke this by typing `/eng-skill-create`, and the agent won't reach for it on its own.

Reach for it when a repeated workflow with a reusable output contract should become a shipped skill in this catalog, and you want the full touch surface (READMEs, plugin and package arrays, CURATED entry, release manifest counts, router, evals) handled mechanically instead of from memory. When the skill already exists and needs improvement, use `/eng-skill-optimize` instead; for feature specs or implementation plans in a target project, use `eng-spec` or `eng-plan`.

## Common questions

**What stops the run before anything is written?**
Three gates: a non-enterprise purpose, a one-off request with no reusable output contract, or a near-neighbor already in the catalog without a recorded boundary. Each cites its evidence; none is a suggestion.

**Why does it ask for confirmation at design freeze?**
Risk, permissions, owner, and maturity are human decisions recorded once in the CURATED table (ADR 0002); the skill proposes, you confirm, then files are written.

**Does it write manifest.yaml by hand?**
Never. Manifests and the registry are generated by `npm run generate:manifests` in the verification stage; hand edits fail the freshness gates.

**Does this skill work across multiple AI agent tools?**
Yes. It supports Claude Code, OpenAI Codex, DeepSeek Harness (DSH), and standard Agent Skills ecosystem tools.

## It's working if

- The run stopped at an intake gate when it should have, with the cited reason.
- Exactly the three scaffold files were created and every checklist item has a matching file change.
- All four gates are green after manifest regeneration, within the 3-repair-round cap.
- The changeset exists and the execution record carries values copied from the generated manifest.

## Where it fits

Catalog meta-skill of the engineering family (ADR 0007): the creation twin of `eng-skill-optimize`, bounded away from project engineering skills by its target, the skill packages of this repository.
