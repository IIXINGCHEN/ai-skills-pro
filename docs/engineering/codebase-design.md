## What it does

Provides the shared vocabulary for designing deep modules: a lot of behaviour behind a small interface, placed at a clean seam, testable through that interface. Use its terms exactly wherever code is designed or restructured.

## When to reach for it

Type /codebase-design, or the agent reaches for it when shaping a new module, splitting a shallow one, or deciding where a seam goes.

## Common questions

**Does this skill work across multiple AI agent tools?**
Yes. It follows the Agent Skills standard used across compatible harnesses.

## It's working if

- The skill executes with clear step-by-step progress and verifiable completion gates.
- Consistent language is the whole point: it stops 'component', 'service' and 'API' from meaning three different things in one design discussion.

## Where it fits

Designing or restructuring modules, planning refactors, or making code more testable and AI-navigable.
