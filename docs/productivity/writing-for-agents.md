## What it does

Reference for writing any document an agent consumes, a skill, an `AGENTS.md`/`CLAUDE.md`, a pointer doc. Covers context pointers, context vs cognitive load budgets, information hierarchy, completion criteria that prevent early exits, and pruning no-op instructions.

## When to reach for it

Type /writing-for-agents when creating or rewriting a skill, `AGENTS.md`, or any agent-facing document.

## Common questions

**Does this skill work across multiple AI agent tools?**
Yes. It supports Claude Code, OpenAI Codex, DeepSeek Harness (DSH), and standard Agent Skills ecosystem tools.

## It's working if

- Pointers are sharply worded with one trigger per branch.
- No-op instructions are removed; completion criteria are checkable.

## Where it fits

Before writing any skill or steering file; pairs with /retro.
