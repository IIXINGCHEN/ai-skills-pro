## What it does

Runs a retrospective on a coding session and suggests improvements to the coding agent's environment, navigation, automated checks, coding standards, AGENTS.md size, tool economy, no-ops, information access, presented in severity order.

## When to reach for it

Type /retro after a session to make future runs better.

## Common questions

**Does this skill work across multiple AI agent tools?**
Yes. It supports Claude Code, OpenAI Codex, DeepSeek Harness (DSH), and standard Agent Skills ecosystem tools.

## It's working if

- Candidates are grounded in the session's primary sources, not guesses.
- Presented in severity order with concrete, actionable suggestions.

## Where it fits

After delivery; feeds into repo guardrails, linters, and steering files.
