## What it does

Turns a difficult incoming message into 2-3 tactful, send-ready replies (gentle / firm / humorous), each with subtext decoding and a one-line rationale. Chinese-first; English supported. Pure advisory skill: it drafts, the user sends.

## When to reach for it

The user pastes a message they received (or describes a tense situation) and needs help replying well: a demanding boss, a difficult client, a family disagreement, an awkward social moment. The skill decodes the other person's real feelings, flags what would escalate, and drafts from a fixed principle library.

## Common questions

**Does it just give me one reply?**
No. It gives 2-3 versions with different stances, each labeled with when to use it, so the user picks the one that fits.

**Is it manipulative?**
No. The red lines forbid deception, gaslighting, and emotional coercion. High EQ here means honesty plus tact, not trickery.

**What if I don't know what I want to achieve?**
The intake has defaults: keep the relationship smooth while staying honest. The skill never blocks on missing answers.

## It's working if

- Replies contain an empathy beat before addressing the issue.
- No version attacks the person or speaks in absolutes.
- The user can explain why each version works in one sentence.
- Chinese output reads naturally.

## Where it fits

Communication skill in the productivity bucket; user-invoked only. Pairs with prod-prompt-enhancer when the user wants to sharpen the wording further.
