## What it does

For ideas too big for one agent session and wrapped in fog: plans the work as a shared map of decision tickets and resolves them one at a time until the way to the destination is visible.

## When to reach for it

Type /wayfinder, or the agent reaches for it when the path forward is unclear and charging at the destination would be wasteful.

## Common questions

**Does this skill work across multiple AI agent tools?**
Yes. It follows the Agent Skills standard used across compatible harnesses.

## It's working if

- The skill executes with clear step-by-step progress and verifiable completion gates.
- It finds the way; it does not charge at the destination. Each resolved decision ticket shrinks the fog.

## Where it fits

Exploring large, ambiguous undertakings before committing to a plan.
