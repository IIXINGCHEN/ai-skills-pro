## What it does

Writes a handoff document summarising the current conversation so a fresh agent can pick the work up, saved to the user's OS temporary directory rather than the workspace.

## When to reach for it

Type /handoff, or the agent reaches for it when a session is getting long and the work must continue elsewhere.

## Common questions

**Does this skill work across multiple AI agent tools?**
Yes. It follows the Agent Skills standard used across compatible harnesses.

## It's working if

- The skill executes with clear step-by-step progress and verifiable completion gates.
- The reply always includes the file's absolute path, and the filename carries a timestamp so handoffs never overwrite each other.

## Where it fits

Compacting a long session into a portable briefing for another agent.
