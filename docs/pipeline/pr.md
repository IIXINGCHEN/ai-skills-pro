## What it does

Writes the PR body using the Summary / Evidence / Merge Danger template: a visual summary, before-and-after evidence, and an explicit merge-danger assessment.

## When to reach for it

Type /pr, or the agent reaches for it when a pull request description needs writing.

## Common questions

**Does this skill work across multiple AI agent tools?**
Yes. It follows the Agent Skills standard used across compatible harnesses.

## It's working if

- The skill executes with clear step-by-step progress and verifiable completion gates.
- Every section earns its place: visuals carry the summary, evidence proves the change works, merge danger states the blast radius.

## Where it fits

Drafting pull request bodies that reviewers can actually evaluate.
