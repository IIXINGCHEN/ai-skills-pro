## What it does

Breaks a plan, spec or conversation into a set of tracer-bullet tickets: thin vertical slices, each declaring the tickets that block it.

## When to reach for it

Type /to-tickets, or the agent reaches for it when a spec or plan needs splitting into ordered, agent-sized work items.

## Common questions

**Does this skill work across multiple AI agent tools?**
Yes. It follows the Agent Skills standard used across compatible harnesses.

## It's working if

- The skill executes with clear step-by-step progress and verifiable completion gates.
- Tickets are local files by default; each one names its blocking edges so the execution order is derivable.

## Where it fits

Decomposing a spec into an ordered ticket graph for implementation.
