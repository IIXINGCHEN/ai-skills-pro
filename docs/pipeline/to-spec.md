## What it does

Takes the current conversation context and codebase understanding and produces a spec. It does not interview the user; it synthesises what is already known, with seam confirmation as the only allowed exception.

## When to reach for it

Type /to-spec, or the agent reaches for it when a discussion has converged and needs freezing into a spec.

## Common questions

**Does this skill work across multiple AI agent tools?**
Yes. It follows the Agent Skills standard used across compatible harnesses.

## It's working if

- The skill executes with clear step-by-step progress and verifiable completion gates.
- The frozen copy always lands at a known path so downstream stages can find it without guessing.

## Where it fits

Turning an explored conversation into an implementation-ready specification.
