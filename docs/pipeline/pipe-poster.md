## What it does

Runs the poster loop for one offer: brief, style, lexicon, render, proofread, Moments post, delivery. One gated, resumable run per poster, with the frozen brief as the single human gate.

## When to reach for it

Type /pipe-poster, or the agent reaches for it when a product poster needs producing from brief to final render.

## Common questions

**Does this skill work across multiple AI agent tools?**
Yes. It follows the Agent Skills standard used across compatible harnesses.

## It's working if

- The skill executes with clear step-by-step progress and verifiable completion gates.
- Rendering scripts are checked in and deterministic; the proofread stage rejects renders with illegible or non-compliant text.

## Where it fits

Producing advertising posters through a repeatable, auditable pipeline.
