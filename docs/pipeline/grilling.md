## What it does

Interviews the user relentlessly until shared understanding is reached, mapping the discussion as a design tree: every decision branches into the decisions hanging off it.

## When to reach for it

Type /grilling, or the agent reaches for it when the user wants their thinking stress-tested, or uses any 'grill' trigger phrase.

## Common questions

**Does this skill work across multiple AI agent tools?**
Yes. It follows the Agent Skills standard used across compatible harnesses.

## It's working if

- The skill executes with clear step-by-step progress and verifiable completion gates.
- It keeps going until the design tree's frontier is empty and the user confirms the shared picture.

## Where it fits

Sharpening a plan, decision or idea before it becomes a spec.
