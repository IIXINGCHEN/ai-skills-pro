## What it does

Moves issues on the project issue tracker through a small state machine of triage roles: categorise, verify, grill if needed, and write agent-ready briefs.

## When to reach for it

Type /triage, or the agent reaches for it when an issue backlog needs sorting into actionable work.

## Common questions

**Does this skill work across multiple AI agent tools?**
Yes. It follows the Agent Skills standard used across compatible harnesses.

## It's working if

- The skill executes with clear step-by-step progress and verifiable completion gates.
- Every issue leaves triage with a role, a category and a brief an agent can execute without further clarification.

## Where it fits

Triaging issue tracker backlogs into agent-ready work items.
