## What it does

Scans a codebase for deepening opportunities, refactors that turn shallow modules into deep ones, presents them as a visual HTML report, then grills through whichever one is picked. The report is a single self-contained file with inline styles and SVG, no external requests.

## When to reach for it

Type /improve-codebase-architecture, or the agent reaches for it when a codebase feels shallow and needs structural deepening.

## Common questions

**Does this skill work across multiple AI agent tools?**
Yes. It follows the Agent Skills standard used across compatible harnesses.

## It's working if

- The skill executes with clear step-by-step progress and verifiable completion gates.
- It plans the improvement as an implementation-ready brief; it does not rewrite the code itself.

## Where it fits

Finding and prioritising architectural deepening work in an existing codebase.
