# PRD: Order Export

## Target User

Account owners who must submit order history to an accounting team each quarter.

## Value Proposition

Removes manual copy-paste from the orders screen into spreadsheets; the export matches accounting's expected column format.

## MVP Scope (P0)

- CSV export of the authenticated account's order history
- Date-range narrowing (from/to)
- Download from the existing orders toolbar

## Non-goals (P1/P2)

- P1: XLSX and PDF formats
- P2: Scheduled recurring exports via email

## Success Metrics

- At least 40% of active accounts use export within 30 days of launch
- Support tickets about order history copy-paste drop by 50%
