# AI Skills Pro 3.1.0 Production Release

Release status: Production
Release version: 3.1.0

## What changed

- Enterprise-only catalog of 40 skills across engineering, productivity, and design buckets, with the user-invoked / model-invoked contract enforced across Claude and Codex metadata.
- Per-skill `manifest.yaml` governance (invocation mode, risk level, permission footprint, governance block with owner/status/maturity/review_due, context budget, dependencies) plus `registry/skills.json` with per-skill content hashes, both generated by `npm run generate:manifests`.
- Knowledge layout doctrine (ADR 0003): artifacts sort into `specs/<feature>/`, `.scratch/`, `docs/adr/`, and `docs/`; vertical-slice tickets in `eng-plan`, consumed in blocking-edge order by `eng-execute`.
- Append-only execution traces (ADR 0004): every orchestrating run appends one execution record per `templates/execution-record.md`.
- Epistemic discipline (ADR 0005): no-fabrication hard rule plus eight operating habits, woven into the skills that need them and guarded by ablation and no-fabrication tests.
- Trigger quality evaluated, not assumed: three-suite trigger eval (train 34, holdout 17, blind 11 cases, all at 100%) plus 20 output-contract checks, wired into CI.
- Network and permission policies under `security/`: per-skill allowed hosts, HTTPS, timeout, and approval expiry; expired or missing approvals block generation.
- Restricted consequential Git, PR, Docker, and Linux firewall operations to human-triggered skills; Skill Tool dependency validation ensures only model-invoked skills can be reached by other skills.
- Zero-dependency test suite of 51 tests plus the validation gate (dependency-graph integrity, manifest freshness, invocation contract, packaging parity) running in CI on every PR and push.
