# Briefing Loop Scenario Starter Templates

Ready-to-use prompt templates for kicking off the Briefing Loop in common workflows.

---

## Scenario 1: Content Creation / Writing

```markdown
I want to write an article on the topic: [Topic].
Target audience: [Audience description].
Core thesis: [One-sentence summary].

Before writing, ask me 3 to 5 critical questions to make the piece targeted, distinctive, and actionable for readers. Do not generate the draft yet.

Once I answer and you play back the confirmed Brief, generate the initial draft followed by a Gap Review self-audit.
```

---

## Scenario 2: Data Analysis

```markdown
I need to analyze this dataset to achieve: [Business objective, e.g., evaluate Q2 campaign performance / forecast quarterly volume].
Target stakeholders: [e.g., Marketing Director / Engineering Lead].

Before proposing analysis frameworks or conclusions, ask me the 3 most essential questions to clarify direction, primary metrics, and required deliverables. Do not start the analysis yet.

After I answer and we freeze the Brief, perform the analysis and attach a Gap Review self-audit.
```

---

## Scenario 3: Decision Support

```markdown
I am evaluating a key decision: [Specific scenario, e.g., feature prioritization / architecture migration].

Before providing recommendations, ask me minimal questions to understand:
- True underlying goals
- Hard constraints and trade-offs
- Known alternative options
- Downside risks of misjudgment
- Cost of waiting or delay
- New information that would change the decision

Once confirmed, provide clear recommendations with pros/cons and a final Gap Review.
```

---

## Scenario 4: Learning Complex Concepts

```markdown
I want to master: [Topic / Concept, e.g., Distributed Consensus / Bayesian Inference].
Current proficiency: [Beginner / Intermediate].
Learning goal: [Practical application / Interview preparation / Exam].

Before explaining, ask me 3 to 5 questions to assess:
- Existing foundational knowledge
- Common points of confusion
- Preferred learning mode (intuitive metaphors, mathematical derivation, or code examples)
- Available time budget

Do not start teaching until I answer and we align on the Brief. Conclude the tutorial with a Gap Review.
```
