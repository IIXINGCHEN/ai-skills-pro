# Long-Term User Context Profile Template

Use this template to initialize persistent user context and preferences across tasks.

```markdown
# Basic Profile
- Role / Occupation: [Specify, e.g., Senior Engineer / Product Lead / Researcher]
- Core Domain / Industry: [Specify, e.g., FinTech, SaaS, Developer Tools]
- Key Skills: [Specify]

# Communication & Tone Preferences
- [ ] Conversational and direct (avoid bureaucratic tone and corporate jargon)
- [ ] Bottom-line up front (BLUF: conclusion first, then elaborate)
- [ ] Short sentences and modular paragraphs for fast scanning
- [ ] Preserve technical terms in original English
- [ ] Concrete examples and verifiable data over generic statements
- [ ] Other preferences: [Specify]

# Target Audience Profile (If applicable)
- Audience Identity: [e.g., Junior Developers / Executive Leadership / End Users]
- Technical Proficiency: [Beginner / Intermediate / Advanced]
- Consumption Context: [Quick triage / Deep research / Executive briefing]

# Deliverable Format Preferences
- Length: [Under 500 words / ~2000 words / Unconstrained]
- Structure: [Overview + Bullets / Narrative + Takeaways / Q&A / Checklist]
- Code & Data: [Full runnable code / Pseudo-code / Tables and charts prioritized]
- Citations: [Required / Optional]

# Negative Constraints (Anti-Patterns to Avoid)
- [ ] Empty slogans and hype (e.g., 'transforming the future')
- [ ] Overly academic or convoluted prose
- [ ] Unverified statistics or hallucinations
- [ ] Lengthy throat-clearing and preamble
- [ ] Other: [Specify]
```
