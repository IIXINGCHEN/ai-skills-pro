# 成文塑形

纯 exploit 阶段：explore 已结束，素材堆已冻结。现在做收敛：定结构，从堆里挖料，一段一段长成文章。

## 定位

- 只做 exploit：不定新主题，不挖新碎片。
- 输入是素材堆（`prod-writing-fragments` 的产出，或任何形态的 raw material：提纲、转文字稿、杂乱草稿都行）。**对本 skill 只读，不改。**
- 产出是另一篇独立的文章文件。

## 开场

1. 通读素材堆全文，先形成"堆里有什么"的整体感，再做任何事。
2. 确认文章文件路径。用户没给就问一次，记住。

## 流程

### 1. 定前置知识（Grounding）

跟用户敲定：读者进门时已经知道什么。规则：

- 每个**概念**被使用前必须先"接地"：要么读者自带（前置知识），要么前文已经建起来。
- 接地的单位是概念不是词：一段话可以没有术语，用的却是读者没有的想法，照样算没接地。
- 有名字的概念（术语），接地等于意思和名字一起落地。
- 维护一张"已接地"清单。杠杆在于取舍：前置要求太多会赶走读者，文内接地太多会淹了开头。跟用户一起定这个度。

### 2. 候选开头

写 2 到 3 个候选开头，每个暗示不同的论点或角度。全部摆出来，让用户选一个或拼一个 hybrid。选定的开头定义了后文必须完成的事。

### 3. 逐段生长

开头落地后，循环：

1. 问："有了这个开头，读者接下来最需要听到什么？"
2. 从素材堆里挖料回答这个问题。下一段只能用已接地的概念；需要新概念就先接地（在这里或提前）。
3. 为这一段的形式吵一架：散文、列表、表格、callout、引用、代码块，每个选择都要有理由（见"格式抉择"）。
4. 达成一致立刻写入文章文件，不要攒批。

用户说停就停。

### 4. 缺料怎么办

素材堆是采石场，不是剧本。挖一条碎片，改写到贴合上下文，放进去；可以拆、可以并、可以转述。

如果文章需要但堆里没有，**明确点名缺口**："这里需要一个例子，堆里没有。你现在给我一个，或者这节砍掉。"不许静默编造。

## 追问的力度

这是 grilling 的反面：ideation 时问"你到底注意到了什么"，这里问"这篇文章到底在论证什么、读者按什么顺序听到"。不许弱过渡滑过去：

- "这段做了上一段没做的什么事？"
- "删掉它，会坏掉什么？"
- "这是散文还是列表？为什么是散文？"
- "这句干了两件事：拆开，或者只留一件。"
- "开头承诺了 X，我们漂到 Y 了。要么绕回来，要么改开头。"

## 格式抉择（跟用户摆到台面上吵）

- **散文 vs 列表**：散文承载论证，列表承载平行项。项与项不真正平行就用散文；真平行就用列表，扫读更快。
- **行内 vs callout**：提示、警告、旁支进 callout，但只有在行内真的会打断主论证时才移出去。
- **表格 vs 重复结构**：同一形状重复 3 次以上且字段一致，用表；否则用加粗开头的散文。
- **引用 vs 转述**：原话本身就是重点才引用；只要意思就转述。
- **代码块 vs 行内代码**：多行、可运行、示例性进块；单个标识符行内。

## 写入节奏

- 每段达成一致立刻追加。每次写前重读文章文件：用户可能在回合间改过。
- 改写某段只动那段，不碰其余。
- 绝不盲目覆盖。

## 与 prod-writing-fragments 的分工

- shape 只成文，不挖新碎片；fragments 只挖碎片，不成文。
- 素材文件对 shape 是只读的。缺口走"缺料怎么办"，不回头重开 explore。

## 越界清单

- 不挖掘堆里没有的新碎片。
- 不改素材文件。
- 不发布、不做平台排版、不加用户没要的前置元数据。

## Checkable Completion Criteria

- [ ] 素材堆已通读，文章文件路径已确认。
- [ ] 前置知识清单已跟用户敲定。
- [ ] 开头由用户选定（2 到 3 个候选摆过）。
- [ ] 每段只用已接地概念；新概念先接地后使用。
- [ ] 每段达成一致后立刻落盘；写前重读，无盲目覆盖。
- [ ] 缺料处已点名（用户补了或砍掉了），无静默编造。
- [ ] 全程未修改素材文件。
