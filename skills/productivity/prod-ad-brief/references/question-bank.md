# Question bank

> 手机回收场景专用题库。其他垂类（餐饮、课程、活动、服务等）请按相同格式自行扩展后再用。

Pick at most three per round, highest impact first. Offer the likely answer inside the question so one word settles it.

| Gap | Question shape |
| :--- | :--- |
| Price anchor | 有没有能公开的价格或价格区间？没有的话我只写“按机况估价”。 |
| Speed promise | 付款是当面结算，还是有固定到账时间？ |
| Licence | 有回收备案或营业执照可以写“正规”吗？ |
| Action | 客户下一步是加微信、打电话，还是到店？ |
| Area | 服务覆盖哪个城市或区域？ |
| Channel | 主要发朋友圈，还是小红书？ |
| Real item | 有这台机器的实拍图吗？有的话海报只用实拍，不用 AI 图。 |
| Price validity | “今日特价”是今天真的有效吗？不是的话我改成“特价”或直接写价格。 |
| Stock | 只有这一台吗？是的话可以写“先到先得”。 |
| Warranty, condition | 成色和质保（几新、保多久、谁来保）确定吗？ |
| Mood | 想要高级克制一点，还是热闹抢眼一点？ |
