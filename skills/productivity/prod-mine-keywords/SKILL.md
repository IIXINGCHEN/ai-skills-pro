# Mine AI Keywords (Google SEO Trend Miner)

Identify, filter, and eng-validate high-potential, newly emerging AI-related keywords from the past 7 days for indie developers, micro-SaaS builders, and SEO tool builders.

## 0. Hard AI Relevance Gate (Mandatory Pre-Filter)

Candidate keywords MUST be directly triggered by AI models, AI products, or AI capability shifts. Non-AI trends (general gaming, memes, celebrities, non-AI calculators) are disqualified immediately.

### Qualified AI Keyword Categories
1. **AI Models & Releases**: New model names, version bumps, new APIs, new modalities (e.g. `GPT-5`, `Claude 3.7`, `Flux 1.1`, `Veo 2`).
2. **AI Products & Tools**: AI agents, AI coding, AI video/image generators, AI search, AI web builders.
3. **Model Derivative Search Intent**: `<model_name> + generator / api / prompt / alternative / pricing / download`.
4. **AI-Enabled Task Shifts**: New tasks generated by model capabilities (e.g. `video generation`, `voice cloning`, `3D generation`, `computer use`, `MCP servers`).
5. **AI Infrastructure & Protocols**: MCP, Agent protocols, AI SDKs, Claude Code capabilities.
---
## 3-Condition Strict Validation Framework

To qualify as a eng-validated "Breakout AI Keyword", a query must pass all 3 conditions:

```
[Condition 1: Recency (≤7 Days)] ➔ [Condition 2: Sustained Growth (Last 3d > First 3d)] ➔ [Condition 3: Search Volume Threshold (≥40% of Baseline)]
```

1. **Recency (7-Day Window)**: Search demand emerged or experienced a sharp inflection point $\le 7$ days ago. (Queries older than 30 days are classified as "Recent Growth", not "New Breakout").
2. **Sustained Growth Momentum**: Split the 7-day Google Trends curve into two halves; the average search interest of the latter 3 days MUST exceed the former 3 days. Eliminate peaks that already collapsed.
3. **Volume Magnitude**: Peak search volume must reach at least **40% of baseline volume** (benchmarked against stable references like ChatGPT, Claude, or Gemini in the same timeframe) to justify a standalone domain/site.

---

## Value Archetypes

- **Type A (High Demand / Low Supply)**: Clear user search intent with minimal competition or dedicated tools. **Highest Priority for Standalone Tools.**
- **Type B (Supply-Led / Newly Released Tech)**: Brand new models or APIs with rapidly growing discovery searches.
- **Type C (Event-Driven / Viral Spike)**: Short-lived viral news or release hype. Best suited for quick content pages rather than permanent SaaS.
