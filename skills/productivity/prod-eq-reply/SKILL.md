# EQ Reply

Turn a difficult message into a reply that is tactful, honest, and effective. This skill decodes what the other person really means, picks a strategy, and drafts replies the user can send with confidence.

## Intake

Establish these four; fill gaps with defaults, never block on questions:

1. **Who**: the other person's relationship to the user and the power dynamic (boss, client, partner, parent, friend). Default: unspecified peer.
2. **What they said**: the original message, pasted verbatim when possible.
3. **Goal**: what the user wants to achieve (defuse, decline, push forward, comfort, set a boundary). Default: keep the relationship smooth while staying honest.
4. **Bottom line**: what cannot be conceded. Default: none stated.

## Decode

Before drafting, work out:

- **Subtext**: what is the other person actually feeling and wanting? Name the emotion, not just the words.
- **Landmines**: which phrases or tones would escalate the conflict if mirrored back.

## Strategy

Pick one or two from the principle library:

1. **Emotion first, facts second**: acknowledge how they feel before addressing the issue.
2. **Give face**: offer the other person a graceful way out; never corner them.
3. **About the issue, not the person**: criticize the thing, never the character. Start sentences with "I", not "you".
4. **NVC four steps**: observation, feeling, need, request. No judgment, no demand.
5. **Leave room**: don't speak in absolutes; keep a way back for both sides.
6. **Humor as cushion**: lighten the mood, never mock.

## Generate

Deliver 2-3 versions, typically gentle / firm / humorous. Each version carries:

- the reply text, ready to send,
- one line explaining why it works (which principle it uses),
- when to use it.

Then invite tuning: "want it firmer, softer, funnier, or shorter?"

## Red lines

- High EQ is not manipulation: no deception, gaslighting, or emotional coercion. Ever.
- Never fabricate facts to make a reply sound better.
- Bullying or harassment: recommend formal channels instead of teaching "tactful endurance".

## Checkable Completion Criteria

- [ ] The four intake elements are established or defaulted.
- [ ] Subtext and landmines are stated before any draft.
- [ ] 2-3 reply versions delivered, each with a one-line rationale.
- [ ] No attacking or demeaning language in any version.
- [ ] Every version contains an empathy beat and leaves room to maneuver.
- [ ] Chinese replies read naturally, with no translated-from-English stiffness.
