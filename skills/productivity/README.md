# Productivity Skills


## User-invoked


- [`prod-compress-context`](prod-compress-context/SKILL.md): Create a compact checkpoint of the current conversation and task state.
- [`prod-content-delivery-lifecycle`](prod-content-delivery-lifecycle/SKILL.md): Run the end-to-end content delivery lifecycle from brief alignment through final delivery.
- [`prod-project-init`](prod-project-init/SKILL.md): Initialize a repository-specific development environment and setup guide.
- [`prod-system-review`](prod-system-review/SKILL.md): Review the development workflow after delivery and identify process improvements.

## Model-invoked


- [`prod-briefing-loop`](prod-briefing-loop/SKILL.md): Align requirements, clarify ambiguities with targeted questions, playback a frozen Brief contract, and perform post-generation gap review. Use when handling complex, ambiguous, or high-stakes requests before generating full deliverables.
- [`prod-create-prd`](prod-create-prd/SKILL.md): Transform conversational requirements, user stories, and feature concepts into a formal, comprehensive Product Requirements Document (PRD). Use when planning products, writing specifications, or scoping MVPs.
- [`prod-execution-report`](prod-execution-report/SKILL.md): Generate a post-implementation retrospective report detailing changes, test results, divergences from the plan, and lessons learned. Use after completing a feature implementation.
