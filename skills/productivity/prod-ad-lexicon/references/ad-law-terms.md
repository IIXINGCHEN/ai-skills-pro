# Advertising Law terms

PRC Advertising Law (《广告法》) Article 9 bars absolute terms; Article 28 bars false or misleading claims. Write the provable version.

| Risky term | Precise compliant term |
| :--- | :--- |
| 最高价, 全网最高, 第一, 顶级, 100% | 按机况估价, 价格透明, 明码报价 |
| 保证, 绝对, 一定 | 支持, 可以, 帮你 |
| 秒到账, 立即到账 | 当面结算, 谈好再交易 (keep the speed only when it is a confirmed claim fact) |
| 正规, 官方, 认证 | Keep only when the licence or partnership is a confirmed claim fact |
| 今日特价, 仅限今天 | Keep only when the price truly expires that day; otherwise 特价 or the bare price |
| 实物实拍 | Keep only when every product pixel is the user's own photo; never on an AI render |
| 先到先得 | Keep only for a single unit or a stated stock count |
| 立即下单 (on WeChat Moments) | 私聊锁定, 评论扣1: Moments has no buy button, so name the real next step |
| Product specs (battery, chip, camera) | Copy from the manufacturer's spec page for that region variant, and cite it |
| Any price, percentage, or time | Keep only when it is a confirmed claim fact |

Slogan energy (秒变现金) is acceptable on a poster headline when no hard promise rides on it; record the call in `copy-lock.md` so the user can veto it. Regulated sectors (finance, health, education, food, recycling filings) add their own checks; list them from the brief's industry checks.
