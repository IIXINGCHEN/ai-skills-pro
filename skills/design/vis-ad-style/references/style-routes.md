# Style routes

All routes share the editorial baseline of styles.refero.design: a strict grid, sharp heavy type, real material texture, generous margins.

## Routing table

| Brief signal | Route |
| :--- | :--- |
| Reward is a physical object or money; mood is lively | **Tactile Pop-Editorial Collage** (default) |
| Professional service; mood is calm or premium | Swiss Grid |
| Many features or a product with modules | Bento Modular |
| A single real item for sale with the user's own photos (used phone, second-hand goods) | **Studio Real-Product** |
| Brand-led, fashion, culture | Neo-Brutalist Editorial Collage |

## Routes

| Route | Texture and objects | Palette |
| :--- | :--- | :--- |
| Tactile Pop-Editorial Collage | Heavy art paper, die-cut stickers with white borders, washi tape, hard offset shadows, highlighter strokes, studio rim light | Base `#FAF7F2` or deep black; accent Hermes orange `#FF5500`, Klein blue `#002FA7`, dopamine green `#00A86B`, or lemon `#FFD600` |
| Swiss Grid | Flat color field, big numerals, thin rules, one cut-out object | Base white or `#111111`; one saturated accent |
| Bento Modular | Rounded tiles on an even rhythm, one benefit per tile, soft shadows | Neutral base; accent on the hero tile only |
| Studio Real-Product | The user's photos cut out and straightened, warm-grey studio sweep, contact shadows, rounded borderless detail crops, ink price panel, full-width accent CTA. Never collage props on real photos: they read as 突兀 | Sweep `#F6F5F2` to `#E8E5E0`; ink `#1C1C1E`; one accent, default `#FF5500` |
| Neo-Brutalist Editorial Collage | Cotton paper, torn edges, vellum sheets, thick black rules | Off-white, charcoal, one signal color |

Type for every route: a heavy geometric sans for headlines, a medium sans for body, both in Simplified Chinese.

## Value leap scene patterns

| Offer type | Scene |
| :--- | :--- |
| Recycling, resale | Worn object bursting into banknotes and coins, a glossy green check bubble |
| Service | Before state on the left, a bright after state on the right, joined by a bold arrow |
| Product | The product lit like a hero, the customer's gain (time, beauty, savings) as floating props |
| Used item for sale | The real unit, back and screen side by side like a studio shot; the value is the price and the proof (grade, warranty, real system screen) |
| Event, course | An empty seat or blank page filling with light, people, or a certificate |
