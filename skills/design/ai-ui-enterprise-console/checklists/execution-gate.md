# Execution Gate Checklist

## Input Gate
- [ ] Mode selected
- [ ] Requirements normalized
- [ ] Missing inputs recorded
- [ ] Priority assigned

## Discovery Gate
- [ ] Domain identified
- [ ] Roles identified
- [ ] Entities identified
- [ ] Workflows identified
- [ ] Existing state mapped (Project Mode)

## Architecture Gate
- [ ] Modules derived
- [ ] Features derived
- [ ] Pages derived
- [ ] Routes defined
- [ ] Permissions defined
- [ ] ADR/ARC recorded

## UI Gate
- [ ] TokenHub style applied
- [ ] Page states defined
- [ ] Responsive behavior defined

## Implementation Gate
- [ ] Files known
- [ ] Dependencies known
- [ ] Complete code produced/changed

## Validation Gate
- [ ] Build checked when available
- [ ] Type checked when available
- [ ] Routes checked
- [ ] Tests checked when available
- [ ] No unverified claim promoted to PASS

## Delivery Gate
- [ ] Traceability complete
- [ ] Limitations listed
- [ ] Final status matches evidence
