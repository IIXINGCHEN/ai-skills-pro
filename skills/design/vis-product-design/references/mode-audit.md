
# Audit

Review the actual supplied experience, not an imagined implementation.

Assess:
- task clarity
- information hierarchy
- affordance
- consistency
- feedback
- loading/empty/error states
- accessibility
- responsive behavior
- motion and distraction
- content clarity

For each finding provide:
- target
- observation
- severity (`P0`, `P1`, `P2`)
- confidence
- recommended fix

Prioritize the highest-impact issues.
Do not redesign unrelated surfaces.

Before executing this skill, read `references/master-prompt.md` and apply its shared rules, especially the `[PARAMETER]` rule, data/UI separation, and quality contract.
