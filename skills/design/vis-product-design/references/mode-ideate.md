
# Ideate

Create three genuinely distinct directions from `PROJECT_CONTEXT`.

For each direction define:
- concept
- composition
- information hierarchy
- typography
- color system
- surface/material
- components
- icon language
- motion language
- responsive behavior
- differentiator

The directions should be meaningfully different, not three recolors of the same template.

Keep project-varying content as `[PARAMETER]` or data.

If image generation is available and visual exploration is useful, create reference visuals for comparison.

Do not build the final prototype until a direction is selected, unless the user explicitly asks to skip ideation.

## Shared contract

Before executing this skill, read `references/master-prompt.md` and apply its shared rules, especially the `[PARAMETER]` rule, data/UI separation, and quality contract.
