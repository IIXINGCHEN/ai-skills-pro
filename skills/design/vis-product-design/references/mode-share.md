
# Share

Before sharing:
1. validate the prototype
2. verify the intended viewport(s)
3. confirm primary interactions
4. select `[SHARE_TARGET]` from available options or connected tools
5. publish only if publication succeeds
6. return the actual shareable result and a concise handoff

Never claim a public URL unless it was actually created.

## Shared contract

Before executing this skill, read `references/master-prompt.md` and apply its shared rules, especially the `[PARAMETER]` rule, data/UI separation, and quality contract.
