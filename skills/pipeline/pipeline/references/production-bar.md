# 生产环境标准（Production Bar）

S8 全局审计的检查清单。有一条不满足就打回 S5。所有条目都是门禁，不是建议。

## 真实性（反虚构 / 反硬编码 / 反模拟）

- **禁止虚构代码**：不许写"看起来能跑、实际没接通"的代码, , 调用不存在的接口、返回固定假值的函数、未接线的 handler，一律不许进交付代码。
- **禁止硬编码**：密钥、URL、阈值、账号、路径等全部走配置 / 环境变量（见"配置与启动"）。
- **禁止模拟代码**：生产代码路径不许出现 mock / 桩 / 演示数据；所有外部调用走真实接口。测试用的 mock 只许出现在测试文件，不许泄漏到生产代码。
- **禁止占位符交付**：TODO / FIXME / `// 以后实现` 不许留在交付代码中；没做完的功能要么做完，要么从本次交付范围中明确拿掉。
- **未验证必须明示**：因环境所限无法验证的真实链路（如真实上游账号、真机部署），必须在审计报告和文档中明确标注"未验证"，不许用模拟代码冒充已实现。

## 路径与跨平台

- **禁止写死绝对路径**：代码、配置、脚本中不许出现 `/home/xxx`、`/root/`、`C:\`、`D:/` 这类与具体机器相关的绝对路径。
- **相对路径优先**：所有路径用相对路径表达（相对于项目根 / 可执行文件 / 配置项指定目录），运行时再解析。
- **路径拼接必须用标准库**：Go 用 `path/filepath.Join`，Node 用 `path.join`；禁止字符串拼接 `/` 或 `\`。
- **系统位置用系统 API**：临时目录用 `os.MkdirTemp` / `os.TempDir()`（不许写死 `/tmp`）；用户家目录用 `os.UserHomeDir()`（不许写死）。
- **跨平台**：换行符、文件权限、子进程调用都要考虑 Windows / Linux / macOS；shell 脚本优先 POSIX sh，必须用 bash 特性的明确注明；S9 注明各平台的验证范围。

## 配置与启动

- 无硬编码：所有可调项走配置文件 / 环境变量
- fail-closed：未配置或非法配置时拒绝启动，不降级裸奔
- 版本号有唯一来源，发布前校验各端一致

## 安全基线

- 密钥扫描干净：无 API key / token / 私钥落盘或进日志
- 敏感数据不记明文日志；错误信息不泄露内部实现细节
- 鉴权 / 限流 / RBAC 按既定基线生效；破坏性操作需二次确认

## 前端

- 零外部网络请求：字体、资源全部本地化或内联
- 构建 0 错误；运行时无 console 报错

## 质量与可观测

- 单元＋集成＋e2e 全绿，且在干净环境重跑结果一致
- 健康检查端点可用；关键路径有日志；失败可定位到原因

## 文档

- API.md / README / CHANGELOG 与实现一致（代码和文档一起修）
- 交付包只收录属于本项目的文件，不含旧文件与非项目文件
